🚀 Insight Hub – A Modern MERN Blog Platform

Insight Hub is a full-stack blogging platform built with the MERN stack (MongoDB, Express, React, Node.js). It allows users to create, read, update, and manage blog posts with a clean UI and a scalable backend. Designed for performance, simplicity, and great reading & writing experiences ✍️📚

🌟 Features

📝 Create, and delete blog posts

👤 User authentication & authorization (JWT-based)

🔐 Secure password hashing

🖼️ Image upload support

📱 Fully responsive UI

⚡ RESTful API with Express & Node.js

🗄️ MongoDB for scalable data storage

🎨 Modern React UI with reusable components
